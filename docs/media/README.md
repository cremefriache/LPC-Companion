# Landing-page media

`cover.svg` is original typography and geometric decoration created for LPC Companion, copyright 2026 LPC Companion contributors. It contains no upstream character art or logos and is offered under the MIT license below.

The selected UI captures include live roleplay screenshots (`usage-*.jpg`) and synthetic inspector/party fixtures in SillyTavern 1.19.0. The studio image is `studio-desktop.png`; narrow repository captures are desktop viewport renders. Bulk maintainer evidence is outside this publication.

Character pixels in those captures retain their original LPC attribution and license requirements. See [upstream and artist attribution](../UPSTREAM.md), [curated credit records](../../assets/lpc/credits-data.json) and [artwork/code notices](../../assets/lpc/NOTICE.md). The original scene art has separate MIT attribution in the [scene catalog](../../assets/lpc/scenes.json). This cover license does not relicense any screenshot or LPC artwork.
