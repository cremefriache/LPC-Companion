LPC Companion — a pixel-art companion for SillyTavern. Named outfits, little scenes and appearance that follows your chat. Manual controls work without a model; model tools are optional. Development preview; install through SillyTavern’s Git URL installer. Actual Android acceptance is pending.

Project: https://github.com/cremefriache/LPC-Companion
