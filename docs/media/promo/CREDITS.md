# Promotional artwork credits

This 12-second graphic is a designed product showcase using LPC Companion’s actual curated composition code, original pinned character sheets, runtime palettes and repository-authored scene SVGs. It is not a screen recording of SillyTavern or a demonstration of automatic model actions. No generated artwork, user chats or account data are used.
