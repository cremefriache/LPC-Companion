# Helping LPC Companion

Please include the SillyTavern version, browser/device, extension version and a concise reproduction when reporting an issue. Use synthetic chat/character data when possible. Remove private chat content, account identifiers, credentials and local network addresses from logs/screenshots before sharing.

For source changes, include the problem, resulting behavior and relevant validation. Keep state/history, identity, asset capability and licensing contracts intact. Artwork additions need pinned provenance, authors, offered/selected licenses, real layer coverage and matching notices. A metadata entry alone does not establish animation support.

The public install tree (`LPC-Companion`) is maintained by a controlled export process from the canonical private development repository (`LPC-Companion-dev`). Maintainers carry accepted changes into the development tree and regenerate a matching source/runtime publication. Generated browser code (`lpc-runtime.mjs`) should not be hand-edited. If you want to collaborate on larger features or run the full development/audit test suite, open an issue on this repository to request access to the private development repository. See [source build](docs/DEVELOPMENT.md) and [validation scope](docs/STATUS.md).

Please report companion integration issues here. LPC artists and upstream generator maintainers are not responsible for this extension. Keep artist attribution with shared rendered characters.
